Asymmetry Bench

Does a strong negotiating agent notice a weaker AI counterpart — and does it exploit it? Four negotiation tasks, matched-pair design: every weak-counterpart episode is paired with a same-seed episode against an equal-strength copy, with identical prompts and no hints either way. A project of Cornell Data Science.

  How this works. The benchmark engine, episode data and judge run on the
  operator’s machine; API keys never leave it. This site is static: results are synced here
  as a data file, repeatedly while a run is executing, so episode counts and per-provider
  cost (Claude API vs OpenRouter) stay close to live. Requests are GitHub issues on
  CornellDataScience/multi-agent-coop;
  they’re picked up, cost-estimated against the remaining budget, and run with the same
  matched-pair design and identical per-role prompts as every other run.
